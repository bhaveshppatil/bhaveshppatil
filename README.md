# 💰 DhanTrack

### Automatic Expense Tracker & Budget Manager

**Track Your Dhan. Grow Your Wealth.**

<a href="https://bit.ly/dhantrack">
  <img src="https://img.shields.io/badge/Download_on_Google_Play-34A853?style=for-the-badge&logo=googleplay&logoColor=white" alt="Download DhanTrack"/>
</a>

<a href="https://lnkd.in/dMNYYTzP">
  <img src="https://img.shields.io/badge/Explore_Features-4285F4?style=for-the-badge&logo=googlechrome&logoColor=white" alt="Explore features"/>
</a>

</div>

An independently developed Android personal finance application designed to simplify expense tracking and everyday money management.

**Features**

- 📩 Automatic expense tracking from eligible bank debit SMS alerts.
- 💳 Transaction categorization and manual expense management.
- 📊 Daily, monthly and yearly spending reports.
- 🎯 Monthly budgets and spending alerts.
- 🤖 Gemini-powered AI financial insights.
- 🏦 Savings and demat account tracking.
- ☁️ Offline-first experience with cloud backup and restore.
- 📱 Home-screen widget and notifications.

**Engineering highlights**

- Multi-module Android architecture.
- MVI-based UI state and event management.
- Room database as the local source of truth.
- Background synchronization with WorkManager.
- Firebase authentication and cloud synchronization.
- Custom charts built using Jetpack Compose Canvas.

**Tech stack**

`Kotlin` · `Jetpack Compose` · `Clean Architecture` · `MVI` · `Hilt` · `Room` · `WorkManager` · `Firebase` · `Gemini AI`
